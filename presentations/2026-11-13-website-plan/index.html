Recommendation

Decap CMS, with drafts.

  1. EditFill in the formEvents, or the site's words.
  2. SaveSave a draftNothing's public yet.
  3. LookPreview itA private link to the real page.
  4. GoPublishOne button.
  5. LiveIt's on the siteIn about a minute.

Why

  • Forms, not code. Jake never sees a file.
  • A preview for every change, before it's public.
  • Each draft is a pull request, so Steve can see and review any change.
  • Free, open source and kept up. The latest release came out in October 2026.

Trade-offs

  • Jake needs a free GitHub account.
  • It needs a small sign-in helper, hosted free on Cloudflare.

Fallback: if a GitHub account is a deal-breaker for Jake, Pages CMS signs him in by email instead, but without the preview step.

Under the hood

Kept small, like the workshop.

  • Its own repoA new lssq-site repo, so it can be handed to Jake whole. The workshop stays here.
  • Plain content filesOne file per event, and one for the site's words. Eleventy turns them into plain HTML pages.
  • Free hostingGitHub Pages, like the workshop. Every draft gets its own preview address.
  • Brand from the sourceThe ribbon, the Q, patterns, colors and type come from the brand files. If Steve's notes change the brand, the site follows.
  • Built for the roadPhone first and light. Works without JavaScript, keeps contrast readable and respects reduced motion.
  • One rule changes Needs OKThe new site gets a small build step to turn content files into pages. The workshop keeps none.

Address: a github.io link to start. A custom domain is Jake's call.

The steps

Five steps to hand-off.

  1. 1Build the pagesHome, events, event pages and contact, in the new style, with sample content.
  2. 2Hook up editingDecap, drafts and preview links.
  3. 3Try itSteve adds a test event, previews it and publishes it.Steve
  4. 4Show JakeFill in real events, links and photos together.Steve and Jake
  5. 5Hand it overJake makes his first edit, then switches over when he's ready.Jake

Event chat stays on WhatsApp for now. It's step 3 of the bigger plan.
